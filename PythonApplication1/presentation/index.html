Your First Steps into Practical AI

Use ChatGPT/Claude daily. Try different prompts. Summarize articles. Generate study plans.

Week 3: Your First AI Script

Call an AI API. Build a sentiment analyzer or text summarizer. ~20 lines of code!

Week 4: Build & Share

Create a mini project. Deploy it. Share on GitHub/LinkedIn. You're now an AI builder!

Workshop: Build a Sentiment Analyzer in 5 Minutes


# Step 1: Install (run once)
# pip install textblob

# Step 2: Import
from textblob import TextBlob

# Step 3: Analyze any text
text = "I absolutely love learning about AI! It's fascinating."
analysis = TextBlob(text)

print(f"Sentiment: {analysis.sentiment.polarity:.2f}")
# Output: Sentiment: 0.63 (positive!)

# Step 4: Try your own sentences!

✅ That's it! You just built an AI-powered tool. No PhD required.
